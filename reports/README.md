# reports/ — human-facing deliverables

This directory holds everything that leaves the lab: weekly status reports,
publication-ready figures, and generated slide decks. Everything here is
**derived** from `results/` (or written by hand from it) — regenerate rather
than edit generated files.

## Layout

```
reports/
├── weekly_report_YYYY-MM-DD.md|tex|pdf   weekly status report to the PI (one date per report)
├── figures/                              publication figures extracted from results
└── decks/                                generated PowerPoint deliverables
```

## Weekly reports

`weekly_report_2026-09-18.md` (with its LaTeX source and compiled PDF) is the
current state of the project: definitions in use (effective frame rate,
noise ceiling), the finding that cross-color correlation is flat in
effective frame rate and grows only with total averaging time, and the
follow-up plan. **Start here** when catching up.

`project_status_summary_2026-09-26.md` is the detailed synthesis of the
weekly report, the 4D Fisher-information derivation
(`proposed_CRLB_Derivation.pdf`), and the corrected response note
(`Proposed_CRLB_response.pdf`), cross-checked against `results/`.
`executive_overview_2026-09-26.tex|pdf` is the plain-language, nontechnical
version of that synthesis for a general audience (compile the `.tex` from
inside `reports/` so `figures/` resolves).

`source_identification_report_2026-10-01.md` identifies what the repeatable
component of the converged signed cross-band correlation actually is: the
corrected disjoint-time-block reliability ladder, disattenuated cross-band
correlations, no-high-pass Sobel congruence maps, the λ-scaling magnification
sweep, segment stationarity with shift search, and the dark-control overlap.
Regenerate the underlying run with `uv run hypercam-source` (see the report's
§Reproduce). **Read this before citing the "80% separation target" claim.**

`amplitude_encoding_report_2026-10-01.md` tests the amplitude channel the
shape analysis could not see: folded (ON+OFF) amplitude maps, flux
normalization against the separable null, SSIM with luminance/contrast/
structure breakdown, log2 gain-ratio maps, and response-vector separability.
Result: the encoding is predominantly brightness-separable (rank-1 response
cloud, resultant 0.99); the chromatic residue is real but small, ordered by
wavelength distance, and spatially unstructured. Regenerate with
`uv run hypercam-amplitude`.

## Adding a report

Weekly reports follow the existing template: a summary up top, a definitions
table, then per-experiment sections that reference figures in `figures/`.
Commit the `.md`, the `.tex` source, and the compiled `.pdf` together.
