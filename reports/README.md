# reports/ — human-facing deliverables

This directory holds everything that leaves the lab: weekly status reports,
publication-ready figures, and generated slide decks. Everything here is
**derived** from `results/` (or written by hand from it) — regenerate rather
than edit generated files.

## Layout

```
reports/
├── weekly_report_YYYY-MM-DD.md|tex|pdf   weekly status report to the PI (one date per report)
├── figures/                              publication figures extracted from results
└── decks/                                generated PowerPoint deliverables
```

## Weekly reports

`weekly_report_2026-09-18.md` (with its LaTeX source and compiled PDF) is the
current state of the project: definitions in use (effective frame rate,
noise ceiling), the finding that cross-color correlation is flat in
effective frame rate and grows only with total averaging time, and the
follow-up plan. **Start here** when catching up.

## figures/

- `cross_correlation_vs_effective_frame_rate.{svg,png}` — the headline plot
  from the duration × accumulation sweep (correlation is set by total
  duration, not effective frame rate).
- `correlation_comparison_poster.{svg,png}` — three-panel comparison of the
  no-filter, Gaussian, and spectral correlation matrices, generated by
  `hypercam-compare` (`uv run hypercam-compare`).

## decks/

- `spectral_correlation_summary.pptx` — stakeholder deck; regenerate with
  `uv run python -m hypercam.reporting.summary_deck` (reads
  `results/spectral_correlation{,_min1,_min5}`).
- `polarity_verification_report.pptx` — ON−OFF polarity verification deck;
  regenerate with `uv run python -m hypercam.reporting.report_deck` (reads
  `results/spectral_correlation_fine_signed`).

## Adding a report

Weekly reports follow the existing template: a summary up top, a definitions
table, then per-experiment sections that reference figures in `figures/`.
Commit the `.md`, the `.tex` source, and the compiled `.pdf` together.
